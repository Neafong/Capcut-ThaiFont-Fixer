# CapCut PC Thai Font & Scale Fixer 🇹🇭

เครื่องมือแก้ไขปัญหา **เมนูภาษาไทยตัวเล็กจิ๋ว / ฟอนต์เพี้ยนเป็น Angsana New** บนโปรแกรม **CapCut PC (Windows)** แบบอัตโนมัติ 1 คลิก!

---

## 📌 ปัญหาเกิดจากอะไร?

1. **ฟอนต์หลักไม่มีภาษาไทย:** ตัวโปรแกรม CapCut PC ถูกออกแบบด้วย Qt6 และเรียกหาฟอนต์ชื่อ `CapCutSansText` ซึ่งไฟล์ดั้งเดิมของโปรแกรม **ไม่มีชุดอักษรภาษาไทยเลยแม้แต่ตัวเดียว**
2. **ระบบ Fallback ดึงฟอนต์โบราณ:** เมื่อโปรแกรมต้องแสดงผลภาษาไทย Windows จึงจำเป็นต้องหาฟอนต์ภาษาไทยในเครื่องมาทดแทนตามลำดับอักษร A-Z ซึ่งตัวแรกที่ Windows เจอคือ **Angsana New** (ขึ้นต้นด้วยตัว A) ทำให้เมนูภาษาไทยกลายเป็นฟอนต์เส้นบาง หัวกลม และมีขนาดเล็กจิ๋วจนแทบอ่านไม่ออกบนจอ Full HD / 2K / 4K
3. **การตั้งค่า High DPI ทั่วไปไม่ได้ผล:** เพราะทางลัดบน Desktop เป็นเพียงตัวเปิด (Launcher) ซึ่ง Windows จะไม่ส่งต่อค่าการปรับขนาดหน้าจอไปยังตัวโปรแกรมจริงที่รันอยู่ข้างหลัง

---

## ✨ เครื่องมือนี้ทำอะไรบ้าง?

* 🔤 **แปลงร่างฟอนต์ Kanit เข้าสู่ระบบ:** นำฟอนต์ **Kanit (คณิต)** ของแท้จาก Google Fonts มาทำการแปลงโครงสร้างตาราง OpenType ภายในตัวฟอนต์ ให้ระบุตัวตนเป็น `CapCutSansText` ทำให้ CapCut ดึงฟอนต์ Kanit ไปเรนเดอร์ภาษาไทยได้โดยตรง คมชัด สวยงาม ทันสมัย 100%
* 🔍 **ปรับสเกลพอดีสายตา (Process-Isolated DPI Scaling):** กำหนดค่าสเกลการแสดงผล (`QT_SCALE_FACTOR`) เฉพาะเจาะจงที่ตัวโปรแกรม CapCut โดยตรง (ค่าเริ่มต้นแนะนำ 1.2x หรือ 120%) **โดยไม่ส่งผลกระทบใดๆ ต่อโปรแกรมอื่นในเครื่องของท่าน**
* ⚡ **คลิกเดียวเสร็จ:** ไม่ต้องเปิดโฟลเดอร์ลึกๆ ไม่ต้องแก้โค้ดเอง รันไฟล์เดียวจบ

---

## 🚀 วิธีใช้งาน (ง่ายมาก!)

1. **ปิดโปรแกรม CapCut** ให้สนิทก่อน
2. ดาวน์โหลดโปรเจกต์นี้ (กดปุ่มสีเขียว **Code** ➡️ **Download ZIP** แล้วแตกไฟล์)
3. ดับเบิลคลิกที่ไฟล์ **`Fix-CapCut.bat`**
4. เลือกขนาดสเกลที่ต้องการ (กด `Enter` เพื่อใช้ขนาดแนะนำ **1.2x** ได้เลย)
5. เปิดโปรแกรม CapCut จากไอคอนหน้าจอ Desktop หรือ Start Menu ตามปกติ เมนูภาษาไทยจะกลายเป็น **Kanit** คมชัดสวยงามทันที!

### 💡 คำแนะนำขนาดสเกลที่เหมาะสม (Scale Guide)

* **สเกล 1.2x (แนะนำที่สุด ⭐):** ขนาดกำลังพอดีสำหรับจอ **Full HD (1080p)** ทำให้ฟอนต์ Kanit คมชัด อ่านง่ายสบายตา โดยที่ปุ่มและเมนูด้านข้างไม่ล้นขอบจอ
* **สเกล 1.25x:** สำหรับคนที่ชอบตัวหนังสือใหญ่ขึ้นอีกนิด
* **สเกล 1.5x:** เหมาะสำหรับหน้าจอความละเอียดสูงระดับ **2K หรือ 4K**
* **สเกล 1.0x:** ขนาดมาตรฐานเดิม 100% (เปลี่ยนเฉพาะแบบอักษร ไม่ขยายขนาด)

> 💡 **หมายเหตุ:** หากในอนาคต CapCut มีการอัปเดตเวอร์ชันใหม่แล้วฟอนต์หลุดกลับไปเป็นตัวเดิม เพียงแค่กดรัน `Fix-CapCut.bat` ใหม่อีกครั้ง ก็จะกลับมาสวยงามเหมือนเดิมทันทีค่ะ
